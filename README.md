# Delayed Notifier

## Описание
**Delayed Notifier** — это бэкенд-сервис для работы с отложенными уведомлениями. Он позволяет создавать уведомления, которые будут отправлены в указанное время, используя RabbitMQ. Сервис обеспечивает надежную доставку с механизмом повторных попыток в случае ошибок. Этот компонент подходит для CRM-систем, образовательных платформ, онлайн-магазинов и других проектов, где требуется функционал отложенных уведомлений.

## Возможности
- **HTTP-эндпоинты**:
    - `POST /notify`: Создание уведомления с указанием даты и времени отправки.
    - `GET /notify/{id}`: Получение статуса запланированного уведомления.
    - `DELETE /notify/{id}`: Отмена запланированного уведомления.
- **Фоновая обработка очереди**:
    - Уведомления отправляются в указанное время.
    - В случае ошибки отправка повторяется с экспоненциальной задержкой.
- **Дополнительно**:
    - Интеграция с Redis для кэширования и быстрого получения статуса.


## Использование
1. Настройте сервис с помощью файла `config.yaml`.
2. Запустите сервис с помощью Docker Compose:
   ```bash
   make run
   ```
3. Используйте предоставленные HTTP-эндпоинты для управления уведомлениями.
